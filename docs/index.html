Quick syntax guide

Use registers r0 to r15. Comments can start with #, ;, or //. Memory operands use offset(base). Branches can refer to labels.

eketsa rd, rs1, rs2eketsi rd, rs1, imm bala rd, offset(base)boloka rs2, offset(base) lekana rs1, rs2, label

04 / Test suiteCheck the assembler using your existing Node.js tests

The test file supplied with your project uses Node.js features such as require() and process. A normal browser cannot execute that file directly.
  1. Keep index.html, assembler.js, and assembler.test.js in the same project folder.
  2. Open a terminal in that folder.
  3. Run node assembler.test.js.
  4. Read the terminal output to see which tests passed or failed.
